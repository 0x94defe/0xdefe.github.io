Sobre mí

Estudio Ingeniería en Informática y me enfoco en desarrollo backend y sistemas de gestión. Me formé con C y Java, y actualmente desarrollo aplicaciones utilizando Python, JavaScript y SQL Server, trabajando desde la base de datos hasta la interfaz.

Uno de mis principales proyectos fue el desarrollo completo del sistema de gestión de una casa cultural. Me encargué de diseñar la base de datos, implementar la lógica de negocio, automatizaciones e interfaz. Actualmente el sistema está en uso y centraliza tareas administrativas que antes se manejaban de forma manual.

Me interesa seguir creciendo en backend, arquitectura de software y sistemas orientados a datos, participando en proyectos donde pueda desarrollar sistemas cada vez más sólidos, escalables y completos.
